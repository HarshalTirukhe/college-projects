# Job Application Tracker

A simple full-stack web application for tracking job applications.

## Features

- Add job applications
- View all applications
- Edit applications
- Delete applications
- Search applications
- Track application status
- Responsive user interface

## Tech Stack

### Frontend
- React
- HTML
- CSS
- JavaScript

### Backend
- Node.js
- Express.js
- MongoDB Native Driver
- CORS

### Database
- MongoDB
